`SELECTORS` - these are used to select the particular block or elements to cosmetic/style  it or place it where ever we want to

# THE syntax for selectors is : 
            `   selector  
                       {
                        property:value;
                       }
`
```
example :  h2
             {
                color:blue;
             }
```

# there are 2 types of selectors :
`1 - CLASS SELECTOR : these can be used more than 1 time to select the element 
```
example :
- HTML/
    <p class="CSS">learning css</p>

- CSS/
    .CSS 
       {
         text-align:centre;
       }
```
# to select the element which are marked by class selectors we need to use .{name assigned}


`2 - ID SELECTOR : these can be used only one time in whole program 
```
example :
- HTML/
     <p id="CSS">learning css</p>
    
- CSS/
      #CSS
          {
            color:blue;
          }
```

# to select the element which are marked by id selectors we need to use #{name assigned}
