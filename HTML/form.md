# Text tags — Forms
```
text — plain single-line text
email — email format validation
password — hides typed characters
number — only accepts numbers, often shows up/down arrows
checkbox — single on/off toggle
radio — pick-one-of-many (needs matching name)
submit — the button that sends the form
date — shows a date picker
file — lets the user upload a file
tel — phone number (no real validation, but mobile keyboards show a number pad)
url — validates it looks like a web address
search — like text, but styled/behaves as a search box (some browsers add a clear "✕")
range — a slider between a min and max value
color — opens a color picker
time — time picker (hours/minutes)
month / week — month or week picker
hidden — invisible field, used to send data the user doesn't need to see/edit
reset — clears the whole form back to defaults
button — a plain button that does nothing on its own (used with JavaScript later)
image — a submit button that's an image instead of text
```
