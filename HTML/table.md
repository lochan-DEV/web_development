# table

```
<table> - it is used to create the table

<thead> - it is used to create the headings of the  table 

<tbody> - it is used to create the rows  of the table

<tr> - it is to maintain or allot the dta inside it as one row 

<th> - it is used to assign the data in the headings

<td> - it is used to allot the data below the headings 
```

# Example
```
<table>
  <thead>
    <tr>
      <th>NAME</th>
      <th>SKILLS</th>
      <th>Status</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Lochan</td>
      <td>python</td>
      <td>beginner</td>
    </tr>
    <tr>
      <td>Lochan</td>
      <td>web development</td>
      <td>beginner</td>
    </tr>
  </tbody>
</table>
```
