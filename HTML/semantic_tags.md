# These are used purely for the coders understanding these do not change or modify the web 
`[these are  used to indicate what each and every line of code is writen and output of it]`

```
<header> — the top section of a page  usually holds a title, logo, and navigation.
<nav> — wraps a group of navigation links .
<main> — the primary, unique content of the page. Only one per page, ever.
<section> — a distinct thematic grouping of content within the page, usually with its own heading.
<article> — a self-contained piece of content that would still make sense on its own, outside this page .
<aside> — content related to the main content but not essential to it .
<footer> — the bottom section of a page  usually holds copyright, contact info, or closing links.
<div> — a block-level container with no semantic meaning at all; used purely for grouping content for layout/styling when no semantic tag fits.
<span> — the same as <div>, but inline — used to wrap and style a small piece of text within a line, without breaking to a new line.
```


# meta useful commands

  <meta name="viewport" content="width=device-width, initial-scale=1.0">    --it adjusts the web as per the users output device
